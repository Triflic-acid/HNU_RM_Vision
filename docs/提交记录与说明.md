### #16 `fa0e27a4` 2026-11-14 · 量测噪声改为距离自适应

**内容**：`kalman_cv.hpp`、`tracking_state.hpp`、`lesson04_tracking.cpp`、`src/main.cpp`。

**说明**：实测径向抖动 80 mm、切向仅 3 mm（差 26 倍），标量 R 无法同时照顾。
改为由针孔几何推导的各向异性 R：

```
σ_lat = Z·σ_px / fx         （横向，∝Z）
σ_dep = Z²·σ_px / (fx·W)    （深度，∝Z²）
```

2 m 处 σ_dep ≈ 82 mm，与实测吻合。
